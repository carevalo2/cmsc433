\textbf{Question.} For each proposed invariant, list the induced initialization,
preservation, and exit verification conditions for this method. Write the
substituted formulas even when the invariant is invalid. Include the post-loop
assignment. This task asks for partial correctness, not termination.
\par\noindent\begin{minipage}{\linewidth}
\begin{lstlisting}
method ThreeTimes(n:int) returns (t:int)
  requires n > 0
  ensures t == 3*n + 2
{
  t := 0;
  var i := n;
  while i > 0 {
    t := t + 3;
    i := i - 1;
  }
  t := t + 2;
}
\end{lstlisting}
\end{minipage}\par
